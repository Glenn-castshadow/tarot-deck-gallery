# Sky Section Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `/sky/` section that reports where the Moon is now, what the sky does this month, which planets are retrograde, and which exact moments touch the reader's own birth chart.

**Architecture:** `sky-calendar-engine.js` is a pure UMD module over the vendored Astronomy Engine, using the same apparent-longitude expression the natal, return and horary engines use. `sky-calendar-text.js` holds original copy tables. `sky-calendar.js` and `sky-calendar.css` render four tabs into a new `#sky-calendar` section on `/sky/`. Independent pyswisseph fixtures validate every astronomical claim.

**Tech Stack:** Vanilla ES2020 browser JS, no build step; `node --test tests/*.test.cjs` (Node 24, via the Bash tool which is Git Bash on this Windows machine); Astronomy Engine 2.1.19 vendored under MIT; pyswisseph in a throwaway venv for fixtures only.

**Spec:** `docs/superpowers/specs/2026-09-13-sky-design.md`

## Global Constraints

- Supported range 1901–2100; out-of-range input returns a status, never throws. (Codebase convention, `NatalEngine`.)
- Longitudes come from `Ecliptic(GeoVector(body, time, true)).elon` — the same expression the natal, chart-in-time and classical engines use, so instants agree by construction. (Codebase convention.)
- Void of course is shown under BOTH traditions, labelled: classical is Lilly's six planets (Sun, Mercury, Venus, Mars, Jupiter, Saturn), modern adds Uranus, Neptune and Pluto. (Glenn, 2026-09-13.)
- Personal transits list the ten natal planets always, and the four angles only when the chart resolved to `ready`; a birthday-only profile gets a stated reason, not silence. (Glenn, 2026-09-13.)
- Eclipses report global circumstances only. The section never claims an eclipse is or is not visible from the reader's location. (Glenn, 2026-09-13.)
- The transiting Moon is excluded from personal transits by default, behind a toggle whose label says why. (My judgement, recorded in the spec: it perfects ~60 exact aspects a month and buries the slower contacts.)
- Voice: symbolic reflection. No "you will", "will happen", "is going to", "the answer is", bare "yes"/"no", "luck" or "fortune". (Codebase convention, tested.)
- Every new astronomical calculation ships independent pyswisseph fixtures generated by a dev-only script under `tools/`. (Codebase convention.)
- No build step; UMD modules; bump `?v=` on every changed file; new files `?v=1`. (Codebase convention.)
- A top-level `const` in a classic script is NOT a `window` property. Guard on bare identifiers. (Codebase convention, learned twice the hard way — see `tests/pages.test.cjs`.)
- Keyboard operable; layouts verified at 390px and 1400px. (Codebase convention.)

```js
const ASPECTS = [0, 60, 90, 120, 180];

function moonIngresses(from, to) {
  const out = [];
  let t = astro.MakeTime(from), end = astro.MakeTime(to);
  while (t.ut < end.ut) {
    const signEnd = Math.floor(natal.mod(lonOf('Moon', t)) / 30) * 30 + 30;
    const hit = astro.Search(x => natal.delta(lonOf('Moon', x), natal.mod(signEnd)), t, t.AddDays(3.5), {dt_tolerance_seconds: 1});
    if (!hit || hit.ut >= end.ut) break;
    out.push(hit);
    t = hit.AddDays(0.01);            // step past the boundary so the next search advances
  }
  return out;
}

// The last exact Ptolemaic aspect the Moon makes to any listed planet inside [a, b].
// Brackets every six hours and searches both chiralities, because astro.Search finds only
// ascending zero crossings -- the same method classical-engine.js uses (see docs/HORARY.md).
function lastAspectBefore(a, b, planets) {
  let latest = null;
  for (const planet of planets) for (const aspect of ASPECTS) for (const sign of (aspect === 0 || aspect === 180 ? [1] : [1, -1])) {
    const g = t => natal.delta(lonOf('Moon', t) - lonOf(planet, t), sign * aspect);
    for (let s = a; s.ut < b.ut; s = s.AddDays(0.25)) {
      const e = s.AddDays(0.25).ut < b.ut ? s.AddDays(0.25) : b;
      const gs = g(s), ge = g(e);
      if (gs < 0 && ge >= 0 && ge - gs < 45) {
        const hit = astro.Search(g, s, e, {dt_tolerance_seconds: 1});
        if (hit && (!latest || hit.ut > latest.time.ut)) latest = {time: hit, planet, aspect};
      }
    }
  }
  return latest;
}

function voidPeriods(from, to, planets) {
  if (!inRange(from) || !inRange(to)) return [];
  const ingresses = moonIngresses(from, to);
  const periods = [];
  let prev = astro.MakeTime(from);
  for (const ingress of ingresses) {
    const last = lastAspectBefore(prev, ingress, planets);
    periods.push({
      start: (last ? last.time.date : prev.date).toISOString(),
      end: ingress.date.toISOString(),
      sign: natal.signNames[signOf(lonOf('Moon', prev.AddDays(0.01)))],
      lastAspect: last ? {planet: last.planet, aspect: last.aspect} : null
    });
    prev = ingress;
  }
  return periods;
}
```

Wire `moonNow`'s `void` key: for each tradition, take the period whose `end` is the next
ingress, and report `isVoid` as whether `date` is at or after its `start`.

The first period in a window is clipped by `from` rather than by a real ingress, so its
`lastAspect` may be `null` for a reason other than a truly void sign. Note this in the returned
object with a `clipped: true` flag on the first period and document it.

const BODIES = ['Sun','Moon','Mercury','Venus','Mars','Jupiter','Saturn','Uranus','Neptune','Pluto'];
// Days a body needs to be certain of covering 30 degrees; the search steps by this much and
// never skips a boundary because each step is bracketed for a single crossing.
const STEP_DAYS = {Sun: 20, Moon: 1.5, Mercury: 10, Venus: 15, Mars: 30,
                   Jupiter: 120, Saturn: 240, Uranus: 600, Neptune: 1200, Pluto: 1200};

function ingresses(from, to, bodies = BODIES) {
  const out = [];
  const end = astro.MakeTime(to);
  for (const body of bodies) {
    let t = astro.MakeTime(from);
    while (t.ut < end.ut) {
      const target = natal.mod(Math.floor(natal.mod(lonOf(body, t)) / 30) * 30 + 30);
      const window = t.AddDays(STEP_DAYS[body]);
      const hit = astro.Search(x => natal.delta(lonOf(body, x), target), t, window.ut < end.ut ? window : end, {dt_tolerance_seconds: 1});
      if (!hit) { t = window; continue; }
      out.push({type: 'ingress', body, sign: natal.signNames[signOf(target)], signIndex: signOf(target), date: hit.date.toISOString()});
      t = hit.AddDays(0.01);
    }
  }
  return out;
}
```

A retrograde body can re-enter a sign it just left, so `ingresses` reports each crossing
including backward ones. Mark direction with `retrograde: speedAt(body, hit) < 0` using the
central-difference speed from Task 4, and say in the docs that a retrograde ingress is a real
event, not a duplicate.

`monthEvents(year, month)` returns `{status:'out-of-range'}` outside 1901–2100, otherwise
builds the UTC month bounds, collects quarters by walking `SearchMoonQuarter`/`NextMoonQuarter`
from the month start, adds `ingresses`, filters to the month, and sorts by date.

// Degrees per day, the same central difference natal-engine.js uses for its retrograde flag.
const speedAt = (body, time) =>
  natal.delta(lonOf(body, time.AddDays(0.5)), lonOf(body, time.AddDays(-0.5)));

const STATION_BODIES = ['Mercury','Venus','Mars','Jupiter','Saturn','Uranus','Neptune','Pluto'];

function stations(from, to) {
  const out = [];
  const end = astro.MakeTime(to);
  for (const body of STATION_BODIES) {
    let t = astro.MakeTime(from), prev = speedAt(body, t);
    while (t.ut < end.ut) {
      const next = t.AddDays(1), speed = speedAt(body, next);
      if ((prev < 0) !== (speed < 0)) {
        const hit = astro.Search(x => (prev < 0 ? 1 : -1) * speedAt(body, x), t, next, {dt_tolerance_seconds: 60});
        if (hit) {
          const longitude = lonOf(body, hit);
          out.push({type: 'station', body, direction: prev < 0 ? 'direct' : 'retrograde',
                    date: hit.date.toISOString(), longitude, sign: natal.signNames[signOf(longitude)]});
        }
      }
      prev = speed; t = next;
    }
  }
  return out.sort((a, b) => a.date < b.date ? -1 : 1);
}
```

```js
const TRANSIT_BODIES = ['Sun','Mercury','Venus','Mars','Jupiter','Saturn','Uranus','Neptune','Pluto'];
const ASPECT_NAMES = {0: 'conjunction', 60: 'sextile', 90: 'square', 120: 'trine', 180: 'opposition'};

function personalTransits(chart, year, month, {includeMoon = false} = {}) {
  if (!chart || !chart.points || !chart.points.length) return {status: 'no-chart', hits: [], angles: false};
  if (year < MIN_YEAR || year > MAX_YEAR) return {status: 'out-of-range', hits: [], angles: false};

  const targets = chart.points.filter(p => p.kind === 'planet')
    .map(p => ({name: p.name, longitude: p.longitude, kind: 'planet'}));
  const angles = chart.status === 'ready' && Array.isArray(chart.axes) && chart.axes.length > 0;
  if (angles) for (const a of chart.axes) targets.push({name: a.name, longitude: a.longitude, kind: 'angle'});

  const start = astro.MakeTime(new Date(Date.UTC(year, month - 1, 1)));
  const stop = astro.MakeTime(new Date(Date.UTC(month === 12 ? year + 1 : year, month % 12, 1)));
  const bodies = includeMoon ? ['Moon', ...TRANSIT_BODIES] : TRANSIT_BODIES;
  const hits = [];

  for (const body of bodies) {
    // Sample once per step and do all aspect arithmetic on the cached longitudes. The fastest
    // body here is the Sun at ~1.02 deg/day, so a daily sample can never skip a crossing; the
    // Moon at ~13 deg/day needs six-hour steps for the same reason.
    const stepDays = body === 'Moon' ? 0.25 : 1;
    const samples = [];
    for (let t = start; t.ut <= stop.ut + stepDays; t = t.AddDays(stepDays)) samples.push({t, lon: lonOf(body, t)});

    for (const target of targets) for (const aspect of ASPECTS) for (const sign of (aspect === 0 || aspect === 180 ? [1] : [1, -1])) {
      const g = lon => natal.delta(lon - target.longitude, sign * aspect);
      for (let i = 1; i < samples.length; i++) {
        const ga = g(samples[i - 1].lon), gb = g(samples[i].lon);
        if (!(ga < 0 && gb >= 0 && gb - ga < 45)) continue;
        const hit = astro.Search(t => natal.delta(lonOf(body, t) - target.longitude, sign * aspect),
                                 samples[i - 1].t, samples[i].t, {dt_tolerance_seconds: 1});
        if (!hit || hit.ut < start.ut || hit.ut >= stop.ut) continue;
        hits.push({date: hit.date.toISOString(), body, aspect, aspectName: ASPECT_NAMES[aspect],
                   target: target.name, targetKind: target.kind, natalLongitude: target.longitude,
                   retrograde: speedAt(body, hit) < 0});
      }
    }
  }
  hits.sort((a, b) => a.date < b.date ? -1 : 1);
  return {status: 'ready', hits, angles};
}
```
