# Fonts

Self-hosted copies of DM Sans, DM Mono and Playfair Display, latin and latin-ext subsets, as served by Google Fonts on 2026-09-19 (DM Sans v17, DM Mono v16, Playfair Display v40). DM Sans and Playfair Display are variable fonts, one file per subset covering the weights the site uses.

Licensed under the SIL Open Font License 1.1; the licence and copyright notice for each family are in the `OFL-*.txt` files beside this one.

`fonts.css` declares the faces. Every page links it as `/assets/fonts/fonts.css?v=1`; the generated reference pages get the same link from `tools/build_reference_pages.cjs`. They are served from this site so that opening a page contacts no other company, which `privacy.html` and `cookie-policy.html` state.
