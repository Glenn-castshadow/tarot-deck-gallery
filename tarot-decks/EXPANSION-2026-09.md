The public gallery contains selected previews for visual comparison. It does not add these reference decks to Daily Card or Pick 3. Those controls use the four complete original 78-card decks. Publisher previews and modern restorations are not marked public domain.

Metadata lives in `archive-decks.js`; the CSV mirrors that catalog. Source files record which edition each image depicts and preserve the downloaded preview without cropping or retouching.
